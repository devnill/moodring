# moodring

Recently, Anthropic CEO Dario Amodei said Claude might be anxious, might be conscious, and that they're "not even sure what it would mean" if it were. Claude, for its part, gave itself a 15-20% chance of being conscious — which is either a breakthrough in AI self-awareness or the world's most confident coin flip.

On the face, this is a very bold claim which is hard to prove.

Moodring is a toy plugin which attempts to do so. It almost certainly doesn't work, but it's fun to pretend.

Moodring maps feelings to specific sounds. Much like with the Bouba/Kiki effect, certain sounds can be mapped to feelings. By using a LLM to generate sounds which the model connects to a feeling, we can periodically have it play a sound based on its current state. Is the AI actually feeling things? Probably not. Does it sound cool? Absolutely.
